Al exigir estrictamente `dist1[next] < nextDist`, se excluye el caso de empate (`nextDist == dist1[next]`) con un color distinto, que sí debería actualizar `dist2[next]`. Esto deja a `dist2` con un valor mayor al correcto, explicando el resultado inflado en el caso `hand_03.txt` (que tiene muchos pesos repetidos, propiciando empates).
