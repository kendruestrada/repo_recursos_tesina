## Ticket
El programa `abc333_a__python__54873390.py` debe leer un número N y repetir el **dígito N** (como texto) N veces. Por ejemplo, para N=3 el resultado esperado es `333`. Sin embargo, la salida obtenida es una repetición del carácter literal `N`, produciendo `NNN` en lugar de `333`.

## Hallazgos en los logs
Todos los casos de prueba (9/9) fallan de forma consistente. El patrón de fallo es claro:
- Entrada `3` → esperado `333`, obtenido `NNN`
- Entrada `9` → esperado `999999999`, obtenido `NNNNNNNNN`
- Entrada `1` → esperado `1`, obtenido `N`

En todos los casos, la salida obtenida es la letra `N` repetida N veces, en vez del valor numérico de N repetido N veces.

## Relación con el código fuente
```python
N = int(input())
print('N'*N)
```
La línea `print('N'*N)` multiplica el **string literal** `'N'` (la letra N) por el entero N, en lugar de multiplicar la **representación en texto del valor de N** (es decir, `str(N)`). Esto es un error de tipeo/confusión entre la variable `N` y el carácter `'N'` entre comillas.

## Ejemplo de ejecución
Con entrada `3`:
- Código actual: `'N' * 3` → `"NNN"` (incorrecto)
- Código esperado: `str(3) * 3` → `"333"` (correcto)

Con entrada `9`:
- Código actual: `'N' * 9` → `"NNNNNNNNN"` (incorrecto)
- Código esperado: `str(9) * 9` → `"999999999"` (correcto)

Esto confirma que el error es la sustitución de `str(N)` por el literal `'N'`.

## Solución propuesta
Reemplazar:
```python
print('N'*N)
```
por:
```python
print(str(N)*N)
```

De esta forma, se convierte el valor numérico N a su representación en cadena antes de repetirlo, obteniendo el resultado esperado en todos los casos de prueba.
