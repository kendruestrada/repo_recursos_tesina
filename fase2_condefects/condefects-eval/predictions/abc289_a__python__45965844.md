**Ticket:** El programa `abc289_a__python__45965844` debe invertir cada bit de una cadena binaria (invertir 0↔1), pero en las pruebas devuelve una cadena de solo ceros en todos los casos donde la entrada no es únicamente "1".

**Hallazgos en los logs:**
- Para entrada `01` se espera `10`, pero se obtiene `00`.
- Para entrada `1011` se espera `0100`, pero se obtiene `0000`.
- Para entrada `100100001` se espera `011011110`, pero se obtiene `000000000`.
- El único caso exitoso es `1` → `0`, un caso trivial donde el encadenamiento de reemplazos no revela el problema porque no hay ceros originales que se vean afectados por el segundo `replace`.

**Relación con el código fuente:**
La línea:
```python
print(input().replace("0", "1").replace("1", "0"))
```
realiza dos reemplazos **secuenciales** sobre el mismo string:
1. `replace("0", "1")`: convierte todos los `0` originales en `1`. Ahora la cadena tiene solo `1`s (tanto los originales como los recién convertidos).
2. `replace("1", "0")`: convierte **todos** los `1` (los originales y los que se generaron en el paso anterior) en `0`.

El resultado final es una cadena compuesta enteramente por `0`s, sin importar la entrada, salvo en el caso trivial de un solo carácter `1`, donde el primer `replace` no tiene efecto (no hay `0`) y el segundo sí funciona correctamente.

**Ejemplo de ejecución:**
Entrada: `"1011"`
- Paso 1: `"1011".replace("0","1")` → `"1111"` (el único `0` se convierte en `1`)
- Paso 2: `"1111".replace("1","0")` → `"0000"`
- Resultado obtenido: `"0000"` (incorrecto)
- Resultado esperado: `"0100"`

Esto confirma que el encadenamiento de `replace` no realiza un intercambio simultáneo de caracteres, sino una sustitución en cascada que termina anulando la inversión.

**Solución o soluciones propuestas:**
1. Usar `str.translate` con una tabla de traducción para hacer el intercambio de forma simultánea:
   ```python
   s = input()
   print(s.translate(str.maketrans("01", "10")))
   ```
2. Alternativamente, usar una comprensión de listas o generador:
   ```python
   s = input()
   print(''.join('1' if c == '0' else '0' for c in s))
   ```
3. Si se desea mantener el estilo con `replace`, usar un carácter temporal como paso intermedio:
   ```python
   s = input()
   print(s.replace("0", "X").replace("1", "0").replace("X", "1"))
   ```

Cualquiera de estas soluciones evita el problema de sustitución en cascada y produce el resultado esperado para todos los casos de prueba.
