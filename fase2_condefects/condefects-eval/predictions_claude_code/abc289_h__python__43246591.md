En una implementación correcta de este algoritmo, en cada iteración del bucle `while` se debe truncar `f` a la longitud relevante en esa iteración (aproximadamente `2*n`), ya que solo esos términos importan para el resultado de baja precisión que se está construyendo. En el código dado, la línea:

```python
fgg = polymul(polymul(g,g),f)
```

usa `f` **completo** (de longitud `T+1`, hasta ~100001) en **todas** las iteraciones del bucle de duplicación, en lugar de `f[:2*n]`. Esto obliga a que la convolución NTT en cada iteración procese un arreglo de tamaño máximo (determinado por `len(f)`) incluso cuando `n` es pequeño, multiplicando el costo real por un factor ~log(N) extra.
