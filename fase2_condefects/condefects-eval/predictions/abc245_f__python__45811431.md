# Análisis del problema

## Ticket
El programa implementa el algoritmo de Kahn (BFS sobre grados) para resolver ABC245-F ("Endless Walk"): se debe contar cuántos nodos permiten un camino infinito, es decir, cuántos nodos pueden alcanzar (directa o indirectamente) un ciclo en el grafo dirigido.

## Hallazgos en los logs
En varios casos (`hand_01`, `hand_05`, `hand_09`, `random_00`, `random_03`, `random_07`) el resultado obtenido difiere drásticamente del esperado. El caso más revelador es `hand_09`:

- Entrada: grafo con N=200000, M=199999, donde **todas** las aristas salen del mismo nodo `30593` hacia el resto de los nodos (grafo tipo estrella, sin ciclos).
- Esperado: `0` (ningún nodo permite un camino infinito, porque no hay ciclos).
- Obtenido: `199999` (el algoritmo casi no elimina nodos).

Esto indica que la propagación del algoritmo de Kahn se detiene prematuramente porque el criterio de "grado cero" está mal calculado.

## Relación con el código fuente

```python
relations[V[i]-1].append(U[i]-1)   # predecesores de V (correcto)
cnt[V[i]-1] += 1                   # BUG: esto calcula in-degree de V
```

Para este algoritmo se necesita:
- `relations[v]` = lista de predecesores de `v` (para propagar la eliminación hacia atrás) → esto está bien.
- `cnt[u]` = **out-degree** de `u` (un nodo sin caminos salientes no puede tener un camino infinito, así que se elimina cuando su out-degree llega a 0).

Sin embargo, el código calcula `cnt[V[i]-1] += 1`, es decir, el **in-degree** de `V`, en lugar del out-degree de `U`. Esto invierte por completo la semántica del algoritmo: en vez de eliminar nodos sin salida (out-degree 0), el código empieza eliminando nodos sin entradas (in-degree 0), lo cual no tiene relación con el problema de "caminos infinitos".

## Ejemplo de ejecución

Grafo: `30593 -> X` para 199999 valores distintos de `X` (todos los demás nodos), sin ciclos.

- **Con el código actual:** `cnt[V-1]` (in-degree) es 0 solo para el nodo `30593` (no es destino de ninguna arista). Se encola solo ese nodo, se elimina, y como nadie apunta hacia él (`relations[30592]` vacío), el proceso termina inmediatamente. Quedan 199999 nodos en `ans` → salida incorrecta `199999`.

- **Con la corrección (`cnt[U[i]-1] += 1`):** el out-degree de `30593` es 199999, y el de todos los demás nodos es 0. Se encolan y eliminan todos los nodos con out-degree 0 (todos excepto `30593`); cada eliminación decrementa el out-degree de `30593` (su único predecesor común), hasta llegar a 0 y eliminarlo también. Al final `ans` queda vacío → salida correcta `0`.

## Solución propuesta

Cambiar:
```python
cnt[V[i]-1] += 1
```
por:
```python
cnt[U[i]-1] += 1
```

para que `cnt` represente correctamente el out-degree de cada nodo, consistente con la propagación hecha vía `relations` (predecesores).
