**Ticket:** El programa indexa incorrectamente la matriz al invertir las variables de fila y columna, causando una salida errónea en los casos donde `r` y `c` tienen valores diferentes.

**Hallazgos en los logs:**
- Los casos `test_07`, `test_10` y `test_11` fallan, todos con `r != c`.
- En cambio `sample_01.txt` (r=1, c=2) pasa porque, casualmente, la simetría de la matriz de entrada (0,1 / 1,0) enmascara el error de indexación.
- Patrón detectado: en todos los fallos, el valor obtenido corresponde exactamente al valor que se obtendría si se intercambian los roles de fila y columna respecto al esperado.

**Relación con el código fuente:**
```python
def main():
    r, c = map(int, input().split())
    a = [list(map(int, input().split()))  for _ in range(2) ]
    print(a[c-1][r-1])
```
La variable `r` representa la fila y `c` la columna (según el enunciado típico de este tipo de ejercicios ABC: "dado r y c, imprimir el elemento en la fila r, columna c"). Sin embargo, la línea `print(a[c-1][r-1])` accede a la matriz usando `c-1` como índice de fila y `r-1` como índice de columna, es decir, **invertidos**. La indexación correcta debería ser `a[r-1][c-1]`.

**Ejemplo de ejecución (validación del error):**

Entrada (`test_07.txt`):
```
2 1
86 58
31 45
```
Aquí `r=2`, `c=1`.

- Matriz: `a[0] = [86, 58]`, `a[1] = [31, 45]`.
- Código actual: `a[c-1][r-1] = a[0][1] = 58` → coincide con el "obtenido" reportado (58).
- Código corregido: `a[r-1][c-1] = a[1][0] = 31` → coincide con el "esperado" (31).

Se confirma el mismo comportamiento en `test_10.txt` y `test_11.txt`, validando que el bug es la inversión de índices.

**Solución propuesta:**
Cambiar la línea:
```python
print(a[c-1][r-1])
```
por:
```python
print(a[r-1][c-1])
```

Esto corrige el acceso a la matriz para que `r` indexe la fila y `c` la columna, tal como se leen desde la entrada, solucionando los tres casos fallidos sin afectar los que ya pasaban (dado que en `sample_01.txt` la matriz es simétrica en su estructura de índices, ambos accesos coinciden con el resultado esperado).
