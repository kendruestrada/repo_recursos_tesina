Análisis del error:

El programa realiza un proceso interactivo en el que imprime consultas con `print("?", *X)` y espera una respuesta del juez a través de `s = int(input())`. El error de ejecución `ValueError: invalid literal` ocurre porque el programa no vacía el buffer de salida tras realizar el `print`. Al ser un problema interactivo en programación competitiva (especialmente en Python), es obligatorio usar `flush=True` en la función `print` para que el juez reciba la consulta y responda, de lo contrario el programa se queda esperando o recibe una entrada vacía/incorrecta.

La línea que más probablemente causa este fallo es la de la llamada a `print` dentro de la función `request`, donde falta el parámetro `flush=True` o `flush` en su defecto.

2. "    print("?",*X, flush=True)"
