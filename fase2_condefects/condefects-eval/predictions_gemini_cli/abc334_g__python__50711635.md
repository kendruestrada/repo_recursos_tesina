El bug en el programa se debe a que la lista `Articulation` puede contener elementos duplicados (un mismo punto de articulación se añade a la lista múltiples veces, una por cada hijo que cumpla la condición para que sea punto de articulación). Al recorrer la lista de puntos de articulación más la raíz sin deduplicar con `set()`, se suman las componentes adicionales (`now`) múltiples veces para un mismo nodo, lo que distorsiona el cálculo total de componentes resultantes tras remover cada nodo y lleva a respuestas incorrectas.

La línea más probable que genera este fallo es la de iteración directa sobre la lista con duplicados, o bien las líneas de declaración y adición de elementos donde se pudo haber utilizado una estructura de conjunto (`set`) para evitar la duplicación.
