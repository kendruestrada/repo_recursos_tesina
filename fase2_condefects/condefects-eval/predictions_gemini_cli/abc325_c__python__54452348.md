   Esta condición hace que si una celda con sensor (`#`) ya ha sido unida a otra celda previamente procesada (su valor en `mtx` cambió de `-1` a `>= 0`), se ignore por completo en el bucle principal. Esto impide que se propague la unión con sus vecinos inferiores y derechos, produciendo respuestas incorrectas (demasiados componentes conexos/islas) en el grafo de adyacencia. 2. **Bug de rendimiento principal (línea 75):**
   ```python
       mtx=mtx+tmp
   ```
   En Python, la concatenación `mtx = mtx + tmp` dentro de un bucle de tamaño $H$ realiza una copia de la lista completa en cada iteración. Esto eleva la complejidad de inicialización a $O(H^2 \cdot W)$, lo cual para matrices de hasta $1000 \times 1000$ requiere aproximadamente mil millones de operaciones elementales de copia, provocando el *timeout* (límite de tiempo excedido) observado en los logs para casos grandes. Debería usarse `mtx.extend(tmp)` o `mtx += tmp` para mantenerlo en $O(H \cdot W)$.
