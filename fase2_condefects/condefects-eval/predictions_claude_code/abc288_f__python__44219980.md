El bug es que el `print(a)` está indentado dentro del bucle `for`, por lo que se imprime el valor parcial de `a` en cada iteración en lugar de imprimir únicamente el resultado final después de terminar el bucle. Si se simula el algoritmo con la entrada de ejemplo (`234`), el valor final de `a` (418) coincide exactamente con la salida esperada, lo que confirma que la lógica de cálculo es correcta — el único problema es la indentación del `print`, que debería estar fuera del `for` (dedentado al mismo nivel que el `for`).
