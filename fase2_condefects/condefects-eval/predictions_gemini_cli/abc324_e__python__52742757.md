2. Se calcula `right[j]`: la longitud del sufijo más largo de $T$ que es subsecuencia de $S_j$.
3. Se determina cuántos pares satisfacen `left[i] + right[j] >= len(T)` (es decir, `left[i] + right[j] >= k`).
