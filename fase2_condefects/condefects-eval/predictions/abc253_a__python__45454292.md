**Ticket:** El programa `abc253_a` debe imprimir "Yes" o "No" según si el segundo valor ingresado (b) es la mediana de a, b, c. Los casos fallidos muestran que la salida esperada es "No" (con N mayúscula) pero el programa obtiene "no" (con n minúscula), causando fallos en comparación exacta de cadenas.

**Hallazgos en los logs:** 
En los tres casos fallidos (example_01, test_01, test_02), el patrón es idéntico: se espera "No" y se obtiene "no". No hay excepciones ni errores de ejecución, es un problema de formato/capitalización en la salida. Los casos exitosos (example_00) confirman que la lógica de "Yes" funciona correctamente.

**Relación con el código fuente:**
```python
a, b, c = map(int,input().split())
l = [a,b,c]
l_2 = sorted(l)
if b == l_2[1]:
  print("Yes")
else:
  print("no")   # <-- aquí está el bug
```
La lógica de determinar si `b` es la mediana es correcta. El problema está exclusivamente en el string impreso en el bloque `else`: se usa `"no"` en minúsculas en lugar de `"No"` con N mayúscula, lo cual no coincide con el formato esperado por el validador del juez (case-sensitive).

**Ejemplo de ejecución:**
Entrada: `2 5 3`
- `l = [2, 5, 3]`, `l_2 = sorted(l) = [2, 3, 5]`
- `b = 5`, `l_2[1] = 3` → `b != l_2[1]`
- Se ejecuta el `else`, imprime `"no"`
- Esperado: `"No"`
- Resultado: FALLO por diferencia de capitalización.

**Solución propuesta:**
Cambiar la línea:
```python
print("no")
```
por:
```python
print("No")
```
para que coincida con el formato esperado por el juez (mayúscula inicial, igual que en "Yes").
