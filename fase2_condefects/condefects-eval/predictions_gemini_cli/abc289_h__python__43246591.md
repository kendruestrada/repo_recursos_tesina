El análisis del código revela que el problema del "timeout" se debe a una ineficiencia en el cálculo de la inversa de la serie formal de potencias en la función `fpsinv`.

### Explicación del bug:
En la función `fpsinv(f, N)`, se implementa el método de Newton para encontrar la inversa de un polinomio. En cada iteración del bucle `while n <= N:`, la variable `n` se duplica. Para calcular el término correctivo, el código ejecuta:
```python
fgg = polymul(polymul(g,g),f)
```
Sin embargo, `f` (que es el polinomio `g` de tamaño `T+1`) se pasa por completo a la función `polymul` (que a su vez llama a `convolution`). Esto significa que, incluso cuando `n` es muy pequeño (por ejemplo, `n = 64`), la función de convolución realiza una transformada rápida de Fourier (NTT) de gran tamaño (proporcional a `T`). 

Al no limitar el tamaño del polinomio `f` a los coeficientes relevantes de grado menor a `2*n` (es decir, usando `f[:2*n]`), el algoritmo realiza múltiples transformadas de tamaño máximo en cada iteración, lo que incrementa drásticamente la complejidad y causa un *timeout* en los casos con `T` grande (como `T = 100000`).

La línea que causa el fallo es:
```python
        fgg = polymul(polymul(g,g),f)
```
La cual debería corregirse como:
```python
        fgg = polymul(polymul(g,g),f[:2*n])
```
