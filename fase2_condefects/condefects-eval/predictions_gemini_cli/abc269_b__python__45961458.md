El error en el código se debe a un error de tipografía en la variable `b` dentro del bucle. En la línea `if b<i : B=i`, se asigna el valor de `i` a una nueva variable con mayúscula `B` en lugar de actualizar `b` (que permanece con su valor inicial `0`). Por esta razón, la salida para la coordenada de la fila máxima (`b+1`) siempre es `1`.

2. "print(a+1,b+1)"
3. "a,b,c,d = 100, 0, 100, 0"
