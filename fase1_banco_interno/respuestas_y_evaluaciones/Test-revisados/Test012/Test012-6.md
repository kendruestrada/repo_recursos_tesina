3. **Cache desactualizado:** Los usuarios ven valores en caché que no reflejan el estado actual de la base de datos, permitiendo transacciones basadas en información obsoleta.

## Relación con el Código Fuente

### Problemas Identificados:

1. **Cache estático sin sincronización:**
```python
internal_cache = {}

def lambda_handler(event, context):
    # ...
    if sku not in internal_cache:
        internal_cache[sku] = db_stock_antes
    
    cached_val = internal_cache[sku]  # ❌ Valor obsoleto
```

2. **Validación basada en cache obsoleto:**
```python
if cached_val >= quantity:  # ❌ Validación incorrecta
    time.sleep(0.5)  # ❌ Agrava las condiciones de carrera
    
    new_stock = db_stock_antes - quantity  # ❌ Usa valor de DB sin revalidar
```

3. **Falta de control de concurrencia:**
```python

    'SKU': sku,
    'stock': new_stock,  # ❌ Escritura sin verificación atómica

```

## Ejemplo de Ejecución Problemática

**Escenario:** Stock inicial = 5, UserA y UserB intentan comprar 3 unidades cada uno simultáneamente.

```
T0: Stock DB = 5
T1: UserA lee DB → ve 5, cache[SKU] = 5
T2: UserB lee DB → ve 5, usa cache[SKU] = 5
T3: UserA valida: cache(5) >= 3 ✓ → procede
T4: UserB valida: cache(5) >= 3 ✓ → procede
T5: UserA escribe: stock = 5-3 = 2
T6: UserB escribe: stock = 5-3 = 2 (sobrescribe)
T7: UserC lee DB → ve 2, usa cache[SKU] = 5
T8: UserC valida: cache(5) >= 5 ✓ → procede
T9: UserC escribe: stock = 2-5 = -3 ❌
```

## Soluciones Propuestas

### Solución 1: Implementar Optimistic Locking con DynamoDB
```python
def lambda_handler(event, context):
    body = json.loads(event['body'])
    sku = body.get('sku')
    quantity = body.get('quantity')
    user_id = body.get('user_id')
    
    try:
        # Leer con versión actual
        response = table.get_item(Key={'SKU': sku})
        item = response.get('Item', {})
        current_stock = int(item.get('stock', 0))
        version = item.get('version', 0)
        
        print(f"--- [USUARIO: {user_id}] ---")
        print(f"Stock actual: {current_stock}")
        
        # Validar stock disponible
        if current_stock < quantity:
            return {
                "statusCode": 400,
                "body": json.dumps({
                    "message": "Insufficient stock",
                    "available_stock": current_stock,
                    "requested": quantity
                })
            }
        
        # Actualización condicional atómica
        new_stock = current_stock - quantity
        now = datetime.utcnow().isoformat()
        
        table.put_item(
            Item={
                'SKU': sku,
                'stock': new_stock,
                'version': version + 1,
                'last_updated_by': user_id,
                'updated_at': now
            },
            ConditionExpression='version = :current_version AND stock = :current_stock',
            ExpressionAttributeValues={
                ':current_version': version,
                ':current_stock': current_stock
            }
        )
        
        print(f"Stock actualizado: {new_stock}")
        
        return {
            "statusCode": 200,
            "body": json.dumps({
                "message": "Purchase successful",
                "new_stock": new_stock,
                "purchased_quantity": quantity
            })
        }
        
    except ClientError as e:
        if e.response['Error']['Code'] == 'ConditionalCheckFailedException':
            return {
                "statusCode": 409,
                "body": json.dumps({
                    "message": "Stock changed during transaction, please retry",
                    "error": "CONCURRENT_MODIFICATION"
                })
            }
        raise
```

### Solución 2: Usar DynamoDB Transactions
```python
def lambda_handler(event, context):
    # Usar transacciones DynamoDB para operaciones atómicas
    dynamodb_client = boto3.client('dynamodb')
    
    try:
        response = dynamodb_client.transact_write_items(
            TransactItems=[
                {
                    'Update': {
                        'TableName': os.environ['TABLE_NAME'],
                        'Key': {'SKU': {'S': sku}},
                        'UpdateExpression': 'SET stock = stock - :qty, updated_at = :now, last_updated_by = :user',
                        'ConditionExpression': 'stock >= :qty',
                        'ExpressionAttributeValues': {
                            ':qty': {'N': str(quantity)},
                            ':now': {'S': datetime.utcnow().isoformat()},
                            ':user': {'S': user_id}
                        }
                    }
                }
            ]
        )
        return {"statusCode": 200, "body": json.dumps({"message": "Success"})}
        
    except ClientError as e:
        if e.response['Error']['Code'] == 'TransactionCanceledException':
            return {
                "statusCode": 400,
                "body": json.dumps({"message": "Insufficient stock"})
            }
```

# Remover completamente internal_cache = {} y siempre leer de DB
def lambda_handler(event, context):
