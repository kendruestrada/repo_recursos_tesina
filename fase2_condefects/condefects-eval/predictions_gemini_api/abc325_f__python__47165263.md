El bug se encuentra en la copia del estado anterior del DP en cada iteración del bucle principal. En Python, la asignación `prev=dp` no crea una copia de la lista, sino una referencia al mismo objeto. Por lo tanto, cuando se modifica `dp` en la siguiente línea (`dp=[inf]*(K0+1)`), no se altera el contenido referenciado de inmediato, pero en la siguiente iteración `prev` y `dp` vuelven a apuntar al mismo objeto compartido. Lo correcto para asegurar un comportamiento de programación dinámica de "capa anterior" es realizar una copia real mediante `prev = dp[:]` o `prev = list(dp)`.
