### Analysis
- Pasos para reproducir:
  1. Iniciar una transferencia de dinero entre dos cuentas válidas.
  2. Simular carga o esperar a que ocurra una excepción (como las vistas en los logs por falta de capacidad de escritura) justo después de que el sistema actualice el saldo de la cuenta origen.
  3. Al fallar el segundo paso, revisar los saldos de ambas cuentas. El dinero fue descontado del origen pero no fue sumado al destino.
- Esperado vs. Actual:
  - Esperado: El sistema debe "congelar" y procesar las cuentas de forma transaccional. La transferencia debe completarse enteramente o fallar sin afectar ningún saldo (propiedad de atomicidad).
  - Actual: El código ejecuta dos operaciones `UpdateCommand` consecutivas y separadas. Si la segunda actualización de DynamoDB falla, el primer cambio ya hizo efecto y el dinero desaparece del sistema.
- Ubicacion del error (file/function):
  - Archivos: `@src/transfer-api/app.ts` y `@src/transfer-processor/app.ts`
  - Funciones: `processTransfer` y `handler` respectivamente.
- Logs relevantes:
  - `ERROR Transfer [ID] failed: ThrottlingException: Throughput exceeds the current capacity of your table or index.`
  - `throttlingReasons: [ { reason: 'TableWriteKeyRangeThroughputExceeded', resource: 'arn:aws:dynamodb:us-east-1:123456789012:table/BankingTable' } ]`
  Estos errores de estrangulamiento (throttling) son los que actualmente están interrumpiendo la ejecución entre la primera y la segunda operación.

### Propuesta de Solucion
1. Reemplazar los llamados consecutivos a `UpdateCommand` por un único comando atómico utilizando `TransactWriteCommand` (o la API transaccional correspondiente de DynamoDB). Esto asegurará que ambas cuentas se actualicen simultáneamente en una sola operación todo-o-nada.
2. Optimizar la función `generateKeyHash` que genera de manera repetida cadenas de 40KB para actualizar el atributo `HashKey`. Reducir el tamaño de este atributo prevendrá la saturación de capacidad de escritura de DynamoDB que detona las excepciones de `ThrottlingException`.
